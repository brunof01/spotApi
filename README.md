# Parking Spot

App Flutter para gerenciar as vagas de estacionamento de um condomínio. Ele consome uma API REST (`https://parking-spot-pmfd.onrender.com/parking-spot`) para listar as vagas cadastradas, mostrando número da vaga, carro (placa, marca, modelo e cor), responsável, apartamento e bloco, e para cadastrar novas vagas por meio de um formulário com validação. O código está organizado em camadas: telas (`lib/screens`), controller (`lib/controllers`), service HTTP (`lib/services`) e model (`lib/models`).
